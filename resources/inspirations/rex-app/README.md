# Rex app screenshots

Screenshots of Superlogical's Rex macOS app (build 1327), taken live on 2026-10-21 at 2x
scale. The UI specification that goes with them is
[`resources/research/clients/rex-ui.md`](../../research/clients/rex-ui.md).

| Image | What it shows |
|---|---|
| `three-splits.jpg` | One tab with three panes (a right split, then a split below). The tab icon is a stack of the three pane icons. |
| `tabs-with-status.jpg` | Seven tabs with status dots, working dots and a blocked message in place of a tab title. |
| `sidebar-tabs.jpg` | Tabs in the sidebar: the host, session and tab tree on the left. |
| `sidebar-activity.jpg` | The Activity view of the sidebar: two-line rows with a status capsule and a relative age. |
| `sidebar-hidden-header-in-titlebar.jpg` | Sidebar mode with the sidebar hidden. The pane header moves up into the title bar. |
| `zoomed-pane.jpg` | A zoomed pane that fills the content area. The header shows only unzoom and close. |
| `glass-untinted.jpg` | Interface style Glass, no tint: neutral gray glass. |
| `classic-tinted.jpg` | Interface style Classic with tint: opaque theme colors and a flat active tab. |
| `classic-untinted.jpg` | Interface style Classic, no tint: opaque system grays. |
| `light-mode.jpg` | The light appearance: tab bar, Activity eye with a dot, ⌘ and + buttons, one pane card. |
| `command-palette.jpg` | The command palette panel (330 pt wide) with its sections and its footer. |
| `settings-server.jpg` | The Settings window on its Server page. |
| `close-tab-tooltip.jpg` | The "Close Tab" tooltip that shows when you hover the × on a tab. |
| `crop-tabbar-left.jpg` | The left end of the tab bar: traffic lights, session button and the selected tab capsule. |
| `crop-tabbar-7tabs-left.jpg` | The left half of a bar with seven tabs. Titles end in a fade, not "…". |
| `crop-tabbar-7tabs-right.jpg` | The right half of the same bar, with the Activity, ⌘ and + buttons. |
| `crop-tab-build-agent-x4.jpg` | Two tabs at 4x zoom: the blue status dot with its cutout on the icon, and a blocked message that scrolls in the selected tab. |
| `crop-pane-corner-gap.jpg` | Two pane cards at high zoom: the corner radius and the 8 pt gap that acts as the divider. |
