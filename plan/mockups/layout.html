Oriel main window: mock-ups for review

Static mock-ups (dark, Glass). Sample data: This Mac runs two herdr sessions, default (five workspaces) and pi-herd (two). Built by plan/mockups/build.py; add ?scene=A to the URL for one scene.

A. Sidebar open: workspaces of one session

Title row, left to right: sidebar toggle, Agents toggle (badge when an agent needs you), the machine (icon only), then the selected workspace's tabs, always in the title row. The sidebar lists the workspaces of one herdr session, like herdr: state icon and name, then the git branch with ahead and behind counts. A worktree workspace sits under its repository. The footer has only the filter and New Session. Swipe the strip sideways to page through the tabs; swipe the sidebar to change the session.

The title row's tabs belong to the selected workspace, so they change when you pick a workspace on this page.

G. Agents view

The Agents toggle turns the sidebar into a list of agents: one row per agent pane, even when a tab holds several. Sorted by priority (needs you, working, done, idle) or by workspace order. Idle agents show by default. Each row says where the agent is; a click opens that workspace, tab and pane.
