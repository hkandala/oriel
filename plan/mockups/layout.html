Oriel main window: mock-ups for review

Static mock-ups (dark, Glass). Sample data: This Mac runs two herdr sessions, default (five workspaces) and pi-herd (two). Built by plan/mockups/build.py; add ?scene=A to the URL for one scene.

A. Sidebar open: workspaces of one session

Title row: sidebar toggle (its icon shows the panel filled while the sidebar is open), the machine (icon only), the selected workspace's tabs (always in the title row), and on the right the Agents button (outline chat bubbles, amber dot when an agent needs you), ⌘ and +. The sidebar lists the workspaces of one herdr session, like herdr: state icon and name, then the git branch with ahead and behind counts. A workspace that is not a git repository shows one line. oriel-rex-ui is a git worktree of oriel, so it sits under oriel. The footer has the filter and Open Session. A sideways swipe on the strip pages through the tabs; a sideways swipe on the sidebar changes the session.

H. Agents view: the agents of this session

A click on the Agents button turns the sidebar into a list of the agents of the session on this page (the first bubble fills while it is on): one row per agent pane, even when a tab holds several. Sorted by priority (needs you, working, done, idle) or by workspace order. Idle agents show by default. A sideways swipe shows the next session's agents. A click opens that workspace, tab and pane.
