Each part of the window has its own page under UI design.

## Machines and workspaces

- A machine is a computer: This Mac or a host you reach with `ssh`, each
  with its own icon. Add Remote Host in the machine menu adds one. herdr on
  the Mac is needed only for This Mac.
- Several windows (⌘N). Each window shows one machine and keeps its own
  selection. When two windows show the same session, the one you last typed
  in controls it, and the other offers **Take Back**.
- A sidebar page per herdr session you open in the window. Swipe the sidebar
  sideways to switch sessions, like Arc's spaces. **Open Session** (⌥⌘T)
  creates a session, starts a stopped one or opens a running one as a page.
- Workspace rows like herdr's: its agents' state as a still icon at the row's
  end (t3code's dashed circle, alert circle and check), the git branch with
  ahead and behind counts, and linked worktrees indented under their
  repository. Rename in place, add a tab, reorder or close a workspace.
- The sidebar resizes from 227 to 480 pt; each window keeps its width.
## Tabs and panes

- Each herdr tab is one page; the window shows the selected tab's page and
  switches at once. The window title follows the selected tab.
- Rex's tab bar, always in the title row: equal-width capsules on a track, a
  selection marker that jumps with every change, titles that fade instead of cutting off, × on hover, a
  context menu, rename in place, drag to reorder, and ⌘1…⌘9 keycaps when you
  hold ⌘ (⌃⌘1…⌃⌘9 on the sidebar's workspaces when you hold ⌃⌘).
- Program icons: each tab shows the overlapping icons of the programs in its
  panes, and at the capsule's end one still icon for **working**,
  **needs you** or **finished**. A tab that needs you or finishes while you are elsewhere
  bounces its icons and says so in its title for 3 s.
- The hover card: rest on a tab to see its panes, and the last
  lines of an agent that needs you. Click a pane to go to it.
- Panes follow herdr's split layout. Drag a divider to resize it, double-click
  it to reset it to half. ⌥⌘= balances all splits.
- Split in four directions, move between cards and swap them with the keys,
  rename a pane, move it to another tab or workspace from its context menu.
- A new pane asks what it runs: Terminal, Agent (Claude Code, Codex, Pi or
  OpenCode, with a loader until it is ready), Browser, File Explorer, Git
  or another plugin with a chooser row.
  Return gives a terminal.
- Browser panes: a web page in a card, with Web Inspector, its own logins
  per machine, the page's icon, and a remote machine's `localhost` through
  the SSH connection. ⌘-click and Open Link in New Tab open a link in a new
  tab. Agents open them beside themselves (`ovvi open browser`).
- Two default plugins, on any machine, each one card with Back and Forward:
  **File Explorer** (a tree that lists each folder as it opens, with a
  filter, git letters, hidden files on a toggle and the root as a path you
  type, and in the same card each file as an editor with the diff's syntax
  colors and breadcrumbs, Markdown with Read, Live Edit, Source and Side by Side and
  an outline, or a preview of images, PDF, audio and video) and **Git** (the
  changes with Stage, Unstage, Revert and Commit, Fetch, Pull and Push, a branch
  menu, the history graph of every branch with Show More, a live Working
  Tree diff, each commit's page, and the diff of any change or commit,
  unified or side by side, with Word Wrap). Edits show the Edited dot, ⌘S saves, and a file
  changed on disk reloads, or asks when there are edits. A click opens in
  the card, ⌘-click in a new tab, ⌥-click in a pane to the side, both in the
  background. Back and Forward show the last five places at once, as you left
  them. Open With shows each app's icon.
- Plugins as packages, as pi's: install from npm, git or a local path in the
  Plugins panel, make a new one from the template (New Plugin…), edit it,
  and press Reload Plugin (⌥⌘R) to build it with its own script and reload
  its cards with their state. A plugin's card says in plain words why it
  does not load (no Node.js, a failed build, not built), with the fix as a
  button and its log one click away. A plugin asks for trust once, showing
  what it can do. File Explorer and Git are plugins the user can edit too.
- Layout changes animate.
- Zoom a pane to fill the window, then return.
- Drag a pane to swap it, place it beside another card, split it into
  another tab, or move it to another workspace, within what herdr allows.
- Float a pane in a small window of its own, above the main window or
  above every app.
- Agents drive Ovvi with one command, `ovvi`, on This Mac and on every
  remote machine: open a browser or plugin card beside themselves or in a
  new tab, float a pane, point the user at a card with a notice and Show,
  copy to the Mac's clipboard, and list, make, build and install plugins.
  They never move the user's view ([Agent control](/docs/agent-control)).
- The overview (⌃⌘O) shows every tab of the session as a miniature,
  browser pages and chats too.
- Find in a pane (⌘F) with the matches highlighted, and ⌘-click links.
- Drop files on a terminal to paste their paths (copied to the machine first
  on a remote card).
- Drop folders on the Dock icon to open a workspace in each.
- Windows and their pages come back after a quit.
- A command palette (⌘K) with every command and its shortcut, in groups
  (Tabs, Workspaces, Sessions, Panes, View, Edit, Plugins), sub-pages for
  renames, moves, appearance and the font size, Go to Directory and Insert
  Path.

## Agents

- **Agents** (a list of statuses, ⌘.): rest on the button to see who needs
  you, or click it for every agent of the session, sorted by priority or by
  workspace order.
- **Chat view:** an agent started from a new pane opens on its TUI. Switch to
  Chat in the card header to see it as messages with a reply box, like
  Messages, on any machine, in a card or a floating window, with the whole
  session and full Markdown (tables, task lists). The agent keeps running.
  The user's messages and the agent's replies are blue and gray bubbles, as
  in Messages. A long chat opens at the bottom with its newest turns, and
  Show Earlier loads the ones before.
  Every message of a turn shows; each run of tool calls between them is one
  line of counts that opens to its calls, and a call opens to its input and
  output. Esc stops the agent. Answer Claude Code's questions
  and OpenCode's permissions in the chat. When the agent asks something else,
  its live terminal shows at the bottom of the card.
- **Relaunch with Chat:** an agent started by hand starts again with a chat,
  in the same session.
- Agent panes show their sessions' own titles in the card, the tab and the
  Agents view.
- Notifications when an agent needs you or finishes. The Dock badge shows the
  number of agents that need you; the Dock menu lists those that need you or
  finished. No sounds.

## Look and settings

- Light, dark or Auto, in two styles: Glass (the desktop shows softly through
  the window) and Classic (an opaque window). Pane cards float on the window
  as translucent cards, the sidebar sits flat, and glass is only on the
  Glass style's tab marker and selected workspace row, and on floating panels.
- Our own program icons, from open-license sets.
- A few settings in the menu bar: appearance, interface style, the text size
  and Focus Follows Mouse. There is no Settings window
  ([Future work](/docs/future-work)).
