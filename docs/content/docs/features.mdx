## Machines and workspaces

- A machine is a computer: This Mac now, SSH hosts later, each with its own
  icon. herdr on the Mac is needed only for This Mac.
- Several windows (⌘N). Each window shows one machine and keeps its own
  selection. When two windows show the same session, the one you last typed
  in controls it, and the other offers **Take Back**.
- A sidebar page per herdr session you open in the window. Swipe the sidebar
  sideways to switch sessions, like Arc's spaces. **Open Session** (⇧⌘N)
  creates a session, starts a stopped one or opens a running one as a page.
- Workspace rows like herdr's: a state icon, the name, the git branch with
  ahead and behind counts, and linked worktrees indented under their
  repository. Rename in place, add a tab, reorder or close a workspace.
- The sidebar resizes from 227 to 480 pt; each window keeps its width.
- **Agents** (the chat bubbles, ⌘.): rest on the button to see who needs you,
  or click it for every agent of the session, sorted by priority or by
  workspace order.

## Tabs and panes

- A strip of tabs: each herdr tab is one page. Swipe sideways through them.
  The tab bar lights every tab whose page is visible and selects the tab when
  the swipe stops. The window title follows the selected tab.
- Rex's tab bar, always in the title row: equal-width capsules on a track, a
  sliding selection, titles that fade instead of cutting off, × on hover, a
  context menu, rename in place, drag to reorder, and ⌘1…⌘9 keycaps when you
  hold ⌘.
- Program icons: each tab shows the overlapping icons of the programs in its
  panes, with three working dots and badges for **needs you** and
  **finished**. A tab that needs you or finishes while you are elsewhere
  bounces its icons and says so in its title for 3 s.
- The hover card: rest on a tab to see its splits and panes, and the last
  lines of an agent that needs you. Click a pane to go to it.
- Panes follow herdr's split layout. Drag a divider to resize it, double-click
  it to reset it to half, or use ⌃⌘ and the arrows. ⌃⌘= balances all splits.
- Split in four directions, move between cards and swap them with the keys,
  rename a pane, move it to another tab or workspace from its context menu.
- Cards without the keyboard fade. Layout changes animate.
- Zoom a pane to fill the window, then return.
- Drag a pane to swap it, place it beside another card, split it into
  another tab, or move it to another workspace, within what herdr allows.
- Find in a pane (⌘F) with the matches highlighted, and ⌘-click links.
- Drop folders on the Dock icon to open a workspace in each.
- Windows and their pages come back after a quit.
- A command palette (⌘K) with every command and its shortcut, sub-pages for
  renames, appearance and folders, Go to Directory and Insert Path.

## Pane kinds

- **Terminal**, **Agent** (any agent that has a herdr integration and is on
  that machine's `PATH`) and **Web page** (any address, drawn natively next to
  your terminals).
- **Git history**, **Diff** and **Markdown** are core plugins: small web pages
  with the same API as yours.
- **Your own plugins**: small web pages (HTML and JavaScript) in a native web
  view, that run commands and reach ports on the pane's machine.

## Agents

- Switch any agent or terminal pane between its terminal and a **chat view**.
  Agents show messages from their own transcript, or the screen text if there
  is no transcript. Terminals show the screen text. The chat view has a reply
  box and buttons to answer a blocked prompt.
- Paste an image into an agent, terminal or chat reply box: the app copies it
  to the pane's machine and pastes its path.
- Notifications when an agent needs you or finishes. The Dock badge shows the
  number of agents that need you; the Dock menu lists those that need you or
  finished. No sounds. Per-status
  switches wait for the Settings window.
- Floating pills (macOS): while you work in another app, a small black pill on
  the screen edge shows a glyph per agent. A blocked or finished agent opens a
  small pill card with its output and a reply box. One click opens the main
  window at that pane.

## iPhone and iPad

- iPad in regular width uses the Mac layout. In compact width (Slide Over,
  narrow Split View) it uses the iPhone layout.
- iPhone shows one pane per page, opens agents in chat, and has a key bar for
  terminals.

## Look and settings

- Light, dark or Auto, in two styles: Glass (the desktop shows softly through
  the window) and Classic (an opaque window). Pane cards float on the window
  as translucent cards, the sidebar sits flat, and glass is only on the
  Glass style's tab marker and selected workspace row, and on floating panels.
- Our own program icons, from open-license sets.
- A few settings in the menu bar: appearance, interface style, the text size,
  and pane options. A Settings window comes later
  ([Future work](/docs/future-work#settings-window)).
- Folders dropped on the Dock icon open a new workspace there.
