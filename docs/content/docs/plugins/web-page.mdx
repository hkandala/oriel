Not built yet. This page is the design ([Pane kinds and plugins](/docs/plugins)).

herdr cannot draw a web page. So a herdr pane holds the place in the layout,
and the app draws a native web view in its rectangle.

## The marker is the pane label

The label is the marker: `oriel:web#<iid> <url>`, for example
`oriel:web#m4p8sa http://localhost:3000/dashboard`
([Labels and instance ids](/docs/plugins/labels)). The label is
the only pane field that has no length limit and survives moves and herdr
restarts (tested on 0.9.3). Metadata tokens are capped at 80 characters and
lost on restart. Titles, process arguments and environment are lost or
invisible.

The address is stored in herdr's session file and shown to every device. Do
not use addresses that contain secrets (for example a `?token=` URL).

## Create

1. The user types an address. A bare `host:port` gets `http://`. Only `http`
   and `https` are accepted. Addresses longer than 1024 characters are refused
   (the label's argument limit).
2. `layout.apply` makes the pane with the label `oriel:web#<iid> <url>` and the
   placeholder command, then `pane.move` puts it in place
   ([Create](/docs/plugins/labels#create)). The placeholder prints
   "web page", the address and "shown by Oriel".
3. After a later edit of the address, `pane.rename {label: "oriel:web#<iid> <url>"}`.
   Another device's open card keeps its page until it is built again or
   **Refreshed** ([When a card reads its state](/docs/plugins/state#when-a-card-reads-its-state)).

## Draw

The same web view as a plugin card (a `WKWebView`,
[Plugin UI](/docs/plugins/plugin-ui)), kept in the PaneViewRegistry so
scrolling away does not reload it. The header shows the page title, Back,
Refresh ([When a card reads its state](/docs/plugins/state#when-a-card-reads-its-state)),
Open in browser and Edit address. Navigation stays inside the
card (like an iframe). The label keeps the address the user typed.

## Viewing state on the machine

The address after in-card navigation and the scroll position are saved on the
pane's machine (D58), in the same instance state file as a plugin's
([The instance state file](/docs/plugins/state#the-instance-state-file)):
`$HOME/.local/state/oriel/<session>/web/<iid>.json`, holding
`{"url": …, "scrollY": …}`.
- Written debounced (500 ms) when a navigation ends or scrolling stops, as for
  plugins. Last writer wins.
- Read when the card is built or on Refresh
  ([When a card reads its state](/docs/plugins/state#when-a-card-reads-its-state)).
- When it reads the file, the card opens the saved address and scroll
  position, else the typed address. That address follows the load rule
  below.
- Editing the address writes the new label and clears the saved address.

## When a page loads by itself

Any process on a machine (a prompt-injected agent, a script) can rename a
pane to `oriel:web#<iid> <url>` or write its state file. So:
- A page the user creates or types loads at once and approves its origin for
  that machine.
- A card built from the machine (a fresh start, another device, a card an
  agent or the herdr TUI made) loads by itself only if its origin is approved
  for that machine or on the safe list. Otherwise it shows "Open ‹url›?"
  once; **Open** approves the origin.
- Approvals are a per-device setting, kept per machine in app storage.
- The safe list: the machine's own `localhost` and `127.0.0.1` on any port
  (always), and built in `github.com`, `gitlab.com`, `bitbucket.org`,
  `developer.apple.com`, `developer.mozilla.org`, `docs.github.com`,
  `vercel.com`, `*.vercel.app` and `*.netlify.app`.
- Settings lists the approvals and the safe list; the user can edit both.

## Remote localhost

On a remote machine, `localhost:3000` means that machine. WebKit never sends
loopback through a proxy. So the app gives the machine's port `<P>` a local
port on this device, through `dial`
([Run and dial](/docs/talking-to-herdr#run-and-dial)) (D52):

- **macOS:** the host's ControlMaster listens on the Mac and forwards each
  connection:
  ```sh
  ssh -F /dev/null -S <ctl> -O forward -L localhost:<P>:localhost:<P> <target>
  ```
- **iOS:** an in-app listener on `127.0.0.1:<P>` pipes each connection it
  accepts into a Citadel `direct-tcpip` channel. Listeners stop when the app
  goes to the background, like terminal streams, and start again on return.

Rules:
- The local port is the same `<P>` when it is free, so the page's origin is
  exactly `localhost:<P>`: OAuth callbacks, CORS lists and absolute URLs keep
  working. If `<P>` is taken (by the Mac itself or another machine's forward),
  the app picks another free port and the origin changes. Simpler choice:
  such a page may break. Revisit when it happens often.
- A navigation decider adds forwards for other remote loopback ports the page
  links to. A forward ends when its last card closes (`ssh -O cancel` on
  macOS).
- Each machine's web cards get a content rule that blocks loopback addresses
  except that machine's own forwards.
- Forwards use no [SSH session](/docs/machines#ssh-sessions).
  They need `AllowTcpForwarding yes` on the server (the default). If a server
  refuses, the card says so.
- **Tailscale and LAN addresses** (`http://devbox:3000`) load directly, with
  no forward, on Mac and iOS.

## Finding ports

- **Open :‹port› chip:** when a frame arrives for a terminal card of the
  selected tab, the app searches the screen text it already holds for
  `https?://(localhost|127\.0\.0\.1|0\.0\.0\.0|\[::1\]):[0-9]+`. A match
  shows "Open :3000" on that terminal's card. A click makes a web pane for that address next to it.
- **Ports list:** the picker's web page entry lists the machine's listening
  ports. It runs `ss -ltnH` (Linux) or `lsof -nP -iTCP -sTCP:LISTEN` (macOS)
  once when the list opens, never on a timer.

## Other rules

- One `WKWebsiteDataStore` per machine: logins persist, and machines stay
  apart.
- Page dialogs show as a sheet on the card, labeled with the origin.
- Plain `http` needs `NSAllowsArbitraryLoadsInWebContent` and
  `NSAllowsLocalNetworking`.
- After a cold restart the pane returns as a plain shell with its label, so
  the page still draws ([Create](/docs/plugins/labels#create)).
