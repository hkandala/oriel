---
title: "Plugin API"
description: "The whole plugin API and how the core plugins use it"
---

The app injects `window.oriel` into every plugin page before it runs.

```ts
interface Oriel {
  pane: {
    machine: { id: string; label: string }; // run and dial go only here
    paneId: string;                          // changes on a cross-workspace move; do not store it
    cwd: string;
    arg: string;
    iid: string;
    plugin: { id: string; version: string; pane: string };
    device: "macos" | "ios";
    apiVersion: number;
    isDevelopment: boolean;
  };

  // both need the "run" permission
  run(
    argv: string[],
    opts?: { cwd?: string; stdin?: string; timeoutMs?: number },
  ): Promise<{ code: number; stdout: string; stderr: string; truncated: boolean }>;
  dial(host: string, port: number): Promise<{
    send(data: string | Uint8Array): void;
    onmessage: ((data: Uint8Array) => void) | null;
    onclose: (() => void) | null;
    close(): void;
  }>;

  setArg(arg: string): Promise<void>;
  state: { get<T>(): Promise<T | undefined>; set<T>(value: T): void };
  snapshot(): HerdrSnapshot | undefined;
  preferences: Record<string, string | boolean>;
  toast(t: { style?: "success" | "failure"; title: string; message?: string }): void;
  open(url: string): Promise<boolean>;        // http(s) only, after a confirm sheet
  clipboard: { copy(text: string): Promise<void> };

  // "pane": pane changed (arg, cwd); "snapshot": herdr state changed;
  // "state": another device wrote the instance state
  on(event: "pane" | "snapshot" | "state", fn: () => void): void;
}
```

| API | Why | How |
|---|---|---|
| `run` | every data need is on the pane's machine: `git`, `cat`, `gh`, `rg`, and the herdr CLI (read panes, prompt an agent) | runs on **that card's machine only**, through the envelope; `argv[0] === "herdr"` becomes the resolved herdr path with `--session`; default cwd is the pane's cwd; 30 s timeout, 4 MiB per stream; one queue per machine, 2 at a time; paused while the card is off screen |
| `dial` | a service on the machine, such as a dev server's API or a database | a TCP stream as seen from **that card's machine only** ([Run and dial](/docs/talking-to-herdr#run-and-dial)); closed when the card closes |
| `pane` | the machine, argument and cwd | injected; `on("pane")` fires on change |
| `setArg` | what this pane shows, kept by herdr | renames its own pane only, keeping `oriel:<plugin>[/<pane>]#<iid>`, then a new `oriel_rev` token |
| `state` | bigger state shared across devices | the state file and the `oriel_rev` signal ([State and restore](/docs/plugins/state)) |
| `snapshot` | refresh when an agent finishes | the snapshot the app already has; `on("snapshot")` is debounced and fires only while the card is visible |
| `preferences` | per-device settings | read only |
| `toast` | errors and progress | a native toast at the card's bottom edge |
| `open` | links in commits, PR pages | `http`/`https` only; a sheet shows the full URL first |
| `clipboard.copy` | "Copy SHA" | write only |

Not in v1: network from the device (`fetch` reaches only the plugin's own
files), clipboard read, file pickers, plugins outside panes (sidebar, status
area, pills), one plugin opening another.

How the core plugins use it:
- **Diff:** argument `base=main`. `run(["git","diff","--no-color",base])`
  again on each `snapshot` event, drawn per file. A "Send comment to agent"
  form calls `run(["herdr","agent","prompt",…])`.
- **Markdown:** argument = a file path; `run(["cat",path])`, rendered with
  raw HTML turned off; the reading position in `state`.
- **Git history:** `run(["git","log",…])` for a list of commits with a detail
  pane from `git show`; `setArg(ref)` from a ref menu; the selected commit in
  `state`.
