---
title: "Plugins on iOS"
description: "The same plugins run on iOS, built-in and your own"
---

- Plugins are web pages, and WebKit is on iOS, so the same plugin runs on the
  iPhone and iPad from day one.
- v1 ships the core plugins and your own plugins on iOS. A plugin only draws
  on the device; its `run` and `dial` go to the pane's machine, as on the Mac.
- The phone has no `git`, so **Install from a git URL** runs the shallow clone
  on a machine you pick, with `run`, and copies the files back with `tar` over
  the same connection. Dev mode (a linked folder) is Mac only.
