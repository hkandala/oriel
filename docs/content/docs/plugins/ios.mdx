---
title: "Plugins on iOS"
description: "The same plugins run on iOS; v1 ships the core ones"
---

Not built yet. This page is the design ([Pane kinds and plugins](/docs/plugins)).

- Plugins are web pages, and WebKit is on iOS, so the same plugin runs on the
  iPhone and iPad from day one. It draws on the device; its `run` and `dial`
  go to the pane's machine, as on the Mac.
- v1 ships only the built-in pane kinds and the core plugins on iOS
  (Terminal, Agent, Web page, Git history, Diff, Markdown), inside the app. Your own plugins on iOS are
  [Future work](/docs/future-work).
- A label for any other plugin shows the missing-plugin card with **Show
  placeholder** (switch the card to the pane's terminal)
  ([State and restore](/docs/plugins/state)).
