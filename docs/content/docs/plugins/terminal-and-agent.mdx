## Terminal

`pane.split` or `tab.create`. herdr starts the user's shell; the card draws
the frame stream ([Terminal plane](/docs/talking-to-herdr#terminal-plane)).
The chat|term switch shows the screen text instead
([Screen-text chat](/docs/chat-view#screen-text-chat)).

## Agent

A pane where herdr detected an agent (`pane.agent` is set, for example
`claude`, `codex`, `pi`).
- **Picker:** the `integration.list` entries with `available: true` (the
  command is on the herdr server's `PATH`), read each time the picker opens,
  so a newly installed agent shows at once. The kind is
  the entry's `label`. Simpler choice: agents without a herdr integration are
  not listed. Start them from a terminal, and herdr still detects them.
  Revisit when users ask for agents that herdr has no integration for.
- **Start:** split or new tab, then
  `agent.start {name: "<kind>-<4 random [a-z0-9]>", kind, pane_id}`.
  - `name` must match `[a-z][a-z0-9_-]{0,31}` and be unique on the machine.
  - A new shell may not be ready: herdr returns `agent_pane_busy`, and the app
    retries every 250 ms for up to 5 s.
  - `agent.start` types the command and returns at once. If no agent appears
    within 10 s, the card shows "Agent did not start" and the last screen
    lines.
- **Icon:** a bundled image per `pane.agent` value (uHerdr's MIT set); unknown
  agents get the SF Symbol `sparkles`.
- **View:** terminal by default on Mac and iPad, chat on iPhone. The chat|term
  switch changes it ([Chat view](/docs/chat-view)).

## Image paste

Paste an image into a terminal or agent card, or into the chat reply box, and
the agent gets it as a file on its own machine (D56).

1. ⌘V (or Paste on iOS) with an image and no text on the clipboard. The app
   encodes it as PNG, at most 10 MB.
2. It writes the image to a new temporary folder on the pane's machine with
   `run`, the PNG on stdin, and reads the path back:
   ```sh
   sh -c 'umask 077; d=$(mktemp -d "${TMPDIR:-/tmp}/oriel.XXXXXX") &&
          cat >"$d/paste.png" && printf %s "$d/paste.png"'
   ```
3. It pastes that path into the pane like a text paste, or adds it to the
   chat draft. Agents such as Claude Code read the image from the pasted
   path.

- The same steps on This Mac and over SSH. uHerdr, collie, termote and
  roamgate do the same: upload, then paste the path.
- Simpler choice: the system's temporary-file cleanup removes old images.
  Revisit when users ask. Dropped files and images paste their paths on This
  Mac ([Drag and drop](/docs/ui/drag-and-drop#files-and-images)).
