Oriel has no Settings window yet (D62). It comes later, designed with
mock-ups first ([Future work](/docs/future-work#settings-window)). Until then
the few settings live in the menu bar, each one key in app storage, per device
([Data](/docs/data#every-piece-of-data)), and everything else uses the defaults
below. Settings that are not on this page do not exist.

Each on/off setting in the menu bar is also a command in the palette, with a
title that says what it does now, for example "Turn On Focus Follows Mouse"
(D48).

## In the menu bar

| Setting | Where | Choices | Default |
|---|---|---|---|
| Appearance | View ▸ Appearance | Auto, Light, Dark | Dark |
| Interface Style | View ▸ Interface Style | Glass, Classic | Glass |
| Text size | View ▸ Increase Font Size (⌘+ or ⌘=), Decrease Font Size (⌘-), Reset Font Size (⌘0) | 8 to 32 pt | 13 |
| Focus follows mouse | View ▸ Pane ▸ Focus Follows Mouse | on, off | off |

- Appearance and interface style: [Theme and accessibility](/docs/ui/theme-and-accessibility#appearance-and-interface-style).
- The text size is the terminal font size. A change applies to every terminal
  at once, without opening its stream again; each card's grid changes, so the
  PTYs resize.
- Focus follows mouse (key `focusFollowsMouse`): a card gets the keyboard
  when the pointer rests on it for 0.15 s, only in the key window
  ([Moving the keyboard](/docs/layout#moving-the-keyboard)).

## Fixed defaults

| What | Value |
|---|---|
| Terminal font | the system monospaced font (SF Mono) |
| Cursor | a blinking block. A program that asks for its own shape (vim's bar in insert mode) gets it: herdr's frames carry the request |
| Option key | types the macOS characters (⌥B is ∫). ⌥← and ⌥→ move by word |
| Copy on select | off |
| Notifications | on for needs you and for finished |
| Dock badge | counts the panes that need you |
| Sounds | none |

What the notifications do: [Agents and notifications](/docs/status#agents-and-notifications).
