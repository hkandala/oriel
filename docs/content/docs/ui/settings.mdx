title: "Settings"

---

Settings is the native macOS Settings window, opened with Oriel ▸ Settings…
or ⌘, (D62). It has four tabs, each a grouped form, about 560 pt wide. Each
setting is one key in app storage, per device
([Data](/docs/data#every-piece-of-data)). Settings that are not on this page
do not exist.

Each on/off setting is also a command in the palette, with a title that says
what it does now, for example "Turn On Focus Follows Mouse" (D48).

## General

| Setting | Choices | Default |
|---|---|---|
| Appearance | Auto, Light, Dark (segmented) | Dark |
| Interface Style | Glass, Classic (segmented) | Glass |

Appearance and Interface Style are also in View ▸ Appearance and View ▸
Interface Style
([Theme and accessibility](/docs/ui/theme-and-accessibility#appearance-and-interface-style)).

## Panes

| Setting | Choices | Default |
|---|---|---|
| Fade inactive panes | on, off | on |
| Focus follows mouse | on, off | off |

What they do: [Fade](/docs/layout#fade),
[Moving the keyboard](/docs/layout#moving-the-keyboard).

## Terminal

| Setting | Choices | Default |
|---|---|---|
| Font | the installed monospaced fonts | the system monospaced font (SF Mono) |
| Font size | 8 to 32 pt (also View ▸ Bigger ⌘+ or ⌘=, Smaller ⌘-, Actual Size ⌘0) | 13 |
| Cursor style | Block, Bar, Underline | Block |
| Blinking cursor | on, off | on |
| Option key acts as Alt | on, off | off |
| Copy on select | on, off | off |

- A change applies to every terminal at once, without opening its stream
  again. A new font or size changes each card's grid, so the PTYs resize.
- The cursor style is the default shape. A program that asks for its own
  shape (vim's bar in insert mode) gets it: herdr's frames carry the request.
- With Option as Alt on, an Option chord on a letter, digit or symbol key
  goes to the program as Alt and that key, Shift included (⌥⇧B is Alt+B), for
  either Option key. ⌥← and ⌥→ always move by word. Off, Option types the
  macOS characters (⌥B is ∫).
- Copy on select puts the selected text on the pasteboard.
