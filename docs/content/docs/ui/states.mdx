---
title: "States"
description: "What the user sees in every connection, pane and error state"
---

Connecting and reconnecting states show at most one line of words and one
button. Empty states (no workspaces, no tabs) show only the button.

| State | What the user sees |
|---|---|
| herdr not installed on This Mac (macOS) | how to install herdr, in a window on This Mac; remote machines work without it |
| Connecting | "Connecting to ‹machine›" with a spinner, after 0.3 s, so a fast connect shows nothing |
| herdr missing on a remote machine | the install command |
| herdr older than 0.9.3 | "herdr 0.9.3 or newer is needed"; before 0.9.1 (no `remote-api-bridge`) "No answer from herdr" |
| herdr updated but not restarted | "Restart herdr on ‹machine›" (terminal streams fail; the API works) |
| herdr server not running on This Mac | "‹session› is not running", a **Start** button (a launchd job, D47), per page: the page stays open and its other pages are not touched; a new window starts `default` by itself |
| herdr server not running on a remote machine | a **Start herdr** button |
| SSH auth failed | ssh's message in plain words |
| Host key changed | the connection is blocked; the new fingerprint is shown |
| Connection lost (Reconnecting) | "Reconnecting to ‹machine›" with a spinner over the cards, dimmed to 0.5; the app retries every 2 s without prompts, then reads a fresh snapshot ([Health check](/docs/machines#health-check)). Also when a page's first connect fails while its server runs |
| Reconnecting needs a password or code | **Reconnect**; only this button may prompt |
| Request timed out (10 s) | "‹machine› did not answer · Retry" in the card or sheet |
| No SSH session left on the connection | the card shows its last image and **Retry** |
| Local Network access denied | "Allow Local Network access for Oriel in System Settings › Privacy & Security" |
| Pane in use on another device | the content (watching) and "In use elsewhere · Take Back" |
| Session controlled in another window | cards dim a little; a bottom capsule "Controlled in another window" with **Take Back** ([Control capsule](/docs/ui/window#control-capsule)) |
| Close a pane that runs a program | "Close ‹title›? ‹program› is running." (a pane that runs only its shell, a web page or a plugin pane closes at once) |
| Close a tab or workspace | always asks, with the pane count |
| No workspaces | a **New Workspace** button, no text |
| A workspace with no tabs | a **New Tab** button with its shortcut, no text |
| New tab or split | the pane picker; herdr is called only after a pick |
| Agent did not start (10 s) | "Agent did not start" and the last screen lines |
| Move refused by herdr | herdr's reason in words, in the notice |
| A drop step failed | the pane stays where it got to; the notice says so |
| Open Session: the name is not a valid herdr name | no Create row |
| Open Session: the session did not start, or its server did not answer within 10 s | the row's spinner stops, the sheet stays open, and a notice capsule in the sheet says "Could not start ‹session›." with herdr's reason and **Retry** |
| Open Session: the page does not connect (the bridge fails) | the page shows the reconnecting state |
| Open Session: a running session stopped before it opened | Open starts it, as for a stopped session |
| A restored page's session no longer runs | the page is skipped |
| Close Page on the last page | Close Page is disabled |
| A write failed | the notice: a capsule with a red symbol, the error and **Retry** when a retry is safe |
| A card's first frame has not arrived | the card's terminal fades in over 0.2 s when it arrives (at once with Reduce Motion) |
| Nobody needs you (Agents button hover) | "Nobody needs you" |
| A session with no agents (Agents view) | an empty list, no text |
| Web page failed | WebKit's error in the card |
| Server refuses port forwarding | "‹machine› does not allow port forwarding" in the web card; Tailscale or LAN addresses still load |
| Web address from the machine, origin not approved | "Open ‹url›?" with an Open button ([Web page](/docs/plugins/web-page#when-a-page-loads-by-itself)) |
| Plugin not installed on this device | the plugin id, the argument, **Show placeholder** (switch the card to the pane's terminal) and **Close pane**; on macOS also **Install from ‹source›…** when the machine suggests it ([State and restore](/docs/plugins/state)) |
| Plugin not responding | "‹title› is not responding · Refresh" |
| Pasted image over 10 MB | "Image too large to paste"; nothing is sent |
| Full chat not available | the screen-text chat, with a tooltip that says why |

How it works: [Checks on connect](/docs/machines#checks-on-connect),
[How a stream ends](/docs/talking-to-herdr#how-a-stream-ends).
