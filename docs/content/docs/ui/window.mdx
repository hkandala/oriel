## Sidebar

Flat on the frosted window background, with no panel (D44).
- Top: the machine's name. Middle: the machine pages, swiped sideways.
- Below them, fixed: page dots (one per machine, clickable).
- Bottom, fixed: the status area
  ([Status area and notifications](/docs/status#status-area-and-notifications)),
  then a Filter field, New Workspace and Add Machine.

A machine is one herdr session ([machine](/docs/reference/glossary)). The
machine page of a non-default session on this Mac is named
"This Mac · ‹session›".

**v0 (D44, D45).** One machine page, the Filter field and New Workspace. Machine
pages, agent rows and the status area come later.

## Machine page

- herdr's workspaces, in herdr's order, as section headers, with their tabs
  as rows (icon tile, label, status glyph). The selected tab is a raised pill
  (D45).
- Later a workspace also lists its agent panes (icon, name, status glyph and
  word), and a collapsed workspace shows how many of its agents need you.
- Clicking a workspace selects it in the app only
  ([Selection and "seen" are the app's own](/docs/layout#selection-and-seen-are-the-apps-own)).

## Tab bar

The title-bar row, while the sidebar is hidden; while it is shown, the tabs
are its rows under each workspace (D45). One capsule per herdr tab; one glass marker
follows the strip as it scrolls, so it sits between two capsules while the strip
is between their pages. A click on a capsule scrolls the strip there, and the
marker moves the same way.
- Each capsule shows the icon of the pane last selected in that tab (the
  first pane if none), and the tab label with the folder part dimmed.
- Each capsule has one status slot. It shows one glyph, in this order of
  priority: × while the pointer is over the tab, then ▲ when an agent needs
  you, then ✓ when one finished and you have not seen it, then ◔ while one
  works. The ◔ glyph does not animate.
- `+` makes a new tab.
- The window title is the selected tab's label, so the Window menu and Mission
  Control show it.

## Strip

- One page per tab, full width, paged.
- Inside a page, pane cards follow herdr's split tree. Drag a divider to
  resize. Double-click a divider to reset it to 0.5. ⌃⌘= makes every split in
  the tab equal.
- Cards without keyboard focus are slightly dimmed.

## Pane card

- Each card has a thin header: kind icon, title, the view switch, zoom and
  close. The view switch is chat|term on agents and terminals, plugin|term on
  plugin panes, and none on web pages.
- On macOS the header controls show on hover. On iOS they always show. Every
  card action is also in the card's context menu and the menu bar; the ⌘K
  palette jumps to tabs, workspaces and sessions, and gets card actions later
  (D48).
- Close asks first unless the pane runs only its shell.

## Zoom

- The zoom button, a double-click on the header, or ⇧⌘↩ zooms a card. It
  fills its tab's page in the strip, as if it were the only pane. Only the
  zoomed card resizes; the others stay, hidden, at their size.
- A split from the zoomed card restores the layout first, so the new pane
  shows.
- The same button or ⇧⌘↩ restores the layout. Esc is not used, because the
  program in the pane needs it.

How it works: [Layout and sizing](/docs/layout),
