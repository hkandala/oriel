The same sheet on macOS and iOS (D54):
- The app saves the machine, connects, and runs the
  [checks on connect](/docs/machines#checks-on-connect).
- On macOS, ssh's questions (an unknown host key, a password) show in the
  askpass dialog ([macOS](/docs/machines#macos)). When herdr is on the Mac,
  the sheet also lists herdr's machines that are not yet added, checked
  while the app's list is empty
  ([The machine list](/docs/machines#the-machine-list)).
- On iOS, the sheet shows the device's public key to copy into
  `authorized_keys`.
- Rename, reorder and remove happen in the app.
- The swipe order is This Mac's sessions first, then the machine list.

Removing a machine never touches herdr on that machine.

How it works: [Machines and SSH](/docs/machines).
