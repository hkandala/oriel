---
title: "Add a machine"
description: "The Add Remote Host dialog"
---

The machine button's "Add Remote Host…" opens the dialog: a glass panel in the
middle of the window, like the palette, that only its buttons close (Esc is
Cancel). Its labels and text are in the primary color, and its fields are
filled and outlined, so they read over light and dark content in every look.
The dialog (D54):
- **Name:** how the machine menu lists the machine; the target when empty.
- **SSH target:** what `ssh` connects to, for example `user@devbox` or a
  host alias from `~/.ssh/config`. Add stays off while it is empty, starts
  with `-` or has a space.
- **Icon:** a button with the icon; it opens a popover with about 140 SF
  Symbols in a grid (computers first, then networks, places and things) and a
  search by symbol name. A server rack for a new machine. The machine button
  shows only the icon, so the icon tells machines apart
  ([Machine button](/docs/ui/window#machine-button)).

Then:
- The app saves the machine and opens a new window on it with its `default`
  session; the window the user added it from keeps its pages. The new window
  connects and runs the
  [checks on connect](/docs/machines#checks-on-connect).
- ssh's questions (an unknown host key, a password, a code) show in the same
  kind of dialog in the new window ([The SSH connection](/docs/machines#the-ssh-connection)).
- The machine menu's "Edit Remote Host ▸ ‹machine›" opens the same dialog
  with the machine's name, target and icon, and Save and Remove. Save keeps the
  edit; the machine's open windows show the new name and icon at once, and
  their next windows and pages use the new target (open sessions stay on the
  connection they have). Remove takes the machine off the list; its open
  windows stay until closed (restored after a relaunch, they open This Mac's
  `default`).
- The machine menu lists This Mac first, then the machine list.

Removing a machine never touches herdr on that machine.

How it works: [Machines and SSH](/docs/machines).
