---
title: "Glossary"
description: "The words these docs use"
---

| Word | Meaning |
|---|---|
| multiplexer | a program that keeps terminals alive in panes, tabs and workspaces, such as herdr or tmux. The app talks to one through the `Multiplexer` interface |
| herdr TUI | herdr's own text interface, run in a terminal app |
| machine / host | a computer that runs herdr: This Mac or an SSH host. Each machine has its own icon and one entry in the machine list. Its sessions share one SSH connection |
| This Mac | the Mac the app runs on |
| session | one herdr server on a machine (`default`, `pi-herd`, …) |
| page | one session's page in the sidebar. A window shows only the sessions the user opened in it; pages swipe sideways. Its title is the session's name, or the machine's name for `default` |
| window | an Oriel window. It shows one machine and keeps its own selection; the user can open several |
| `HostStore` | the app's live model of one open session, shared by every window that has its page |
| machine button / workspace button | the title-row button with the machine's icon / the title-row button "‹page title› \| ‹workspace›", shown while the sidebar is collapsed |
| Open Session | the panel that adds a session to the window as a page: it creates a session, starts a stopped one or opens a running one (⌥⌘T) |
| strip / tab page | the main area that pages sideways / one tab's page in it |
| tab capsule | one tab in the tab bar |
| lit tab | a tab whose page is visible in the strip |
| pane card | how the app draws one herdr pane: a header plus content. A browser's, a plugin's or an agent's header has a second row for its kind's controls |
| chooser | the list a new pane shows first: Terminal, Agent, Browser, File Explorer or Git |
| browser pane | a herdr pane labeled `oriel:browser#<iid> <url>`, which the app draws as a web page |
| plugin pane / default plugins | a herdr pane labeled `oriel:<kind>#<iid> <arg>` that the app draws / the two kinds that come with the app: File Explorer and Git |
| web card | a browser or plugin card, whose content is a web view of its own; a plugin's page comes from the app's `web/` bundle |
| picture (card) | a card's last image at 1x, shown over a web card as it comes back, in place of a dropped one, and in its overview tile |
| bridge (plugin) | the fixed messages between a web card's page and the app: asks with a JSON answer, reports, and messages from the app |
| linked open | an open from a plugin card in a new herdr tab right after its card's tab (⌘-click), or in a pane to its side (⌥-click) |
| landing | the line, diff file or row an open scrolls to, once, on the page's first load |
| Back and Forward (plugin) | a plugin card's own list of the places it showed, walked from row 2 or with ⌘[ ⌘] |
| Edited dot | the dot after a plugin card's title while File or Markdown has unsaved edits |
| Git home | a Git card's first page: the branch, Fetch, Pull, Push, Commit, the changes and the history of every branch |
| toast | a one-line glass capsule at the top of a plugin card with two buttons, for example Reload or Keep Mine |
| info view | a plugin card's view of a file it does not show: the type's icon, the name, the kind and the size |
| jump bar | File's row 2: `folder › file › symbol at the caret` |
| chat view | an agent pane drawn as messages with a reply box, for agents Oriel started with its flags. The card's Chat \| TUI switch flips between it and the agent's TUI (its own terminal interface) |
| Relaunch with Chat | the button that starts an agent running without Oriel's flags again with them, in the same session |
| session title | the name an agent keeps for its session (Claude Code, Codex and OpenCode make one; pi's `/name` sets one), shown as the agent pane's name unless the pane has a herdr label |
| launch line / marker | the command and flags the chooser types to start an agent with a chat / the part of it (a UUID in an argument) by which the app knows the pane again |
| adapter | one agent's side of the chat view: its launch line, marker, followers, Stop keys and answers (`ChatAdapter`) |
| side files | the hooks' and plugins' small files under `~/.cache/oriel/` on the pane's machine |
| pi-oriel | the small pi extension that ships inside Oriel and reports pi's session, tree moves, dialogs and phase |
| detail level | how much of a turn the chat shows: Replies only, Activity or Everything, picked in the header's level pill |
| live terminal (drawer) | the pane's terminal at the bottom of a chat card while the agent asks something the chat cannot answer |
| iid | a browser or plugin pane's instance id: 6 characters of `[a-z0-9]` in its label; a browser's names its state file |
| placeholder | the small script a browser or plugin pane runs in herdr, so herdr's TUI shows what the pane is |
| keyboard card | the card that gets typed keys, one per tab; the app's own choice, never herdr's focus |
| program icon | the icon of the program that runs in a pane, from Oriel's own catalog; a tab shows a stack of them |
| hover card | the panel that shows a tab's panes when the pointer rests on a title-bar tab or an Agents row |
| overview | every tab of the session as a live miniature, grouped by workspace (⌃⌘O) |
| floating pane | a pane shown in a small window of its own; herdr keeps it in its tab |
| float request | a tool in a pane asks Oriel to float a pane, through herdr's pane metadata tokens |
| notice | the short capsule at the bottom of the strip after a failed action |
| Glass / Classic | the two interface styles: a window with a behind-window blur / an opaque window |
| Appearance | Auto, Light or Dark |
| Agents button | the title-row button with a list of statuses; resting on it lists the agents of the page in view that need you, then those done |
| Agents view | the sidebar page's list of every agent pane of its session, turned on with the Agents button, ⌘. or View ▸ Show Agents |
| Take Back | the button that moves control of a session to this window, or of a pane to this device |
| OSC 7501 | the Program Status Protocol: an escape sequence a program writes to its terminal to report idle, working, blocked, done or error. herdr does not read it yet; the app reads status only from herdr |
| working dots | three dots that pulse in step on every tab while an agent works (blue) |
| plain-text title | a tab's or pane's title where it cannot dim its second part (⌘K, menus, window titles): the two parts joined by ` \| ` |
| badge | a 7 pt dot on a program icon or the Agents button: amber when an agent needs you, green when a finish is not seen |
| state icon | a workspace row's sign of its strongest agent state: an amber dot, the working dots, a green dot or a gray ring |
| status word | working (blue), needs you (amber), finished (green), idle (gray); always next to a dot or badge for VoiceOver |
| seen | this device has shown the agent's last finish to the user: its tab was selected on the page in view of the key window |
| git state | a workspace row's branch and its ahead and behind counts, from `git status` on the machine |
| PTY | the pseudo-terminal a shell runs in; it has one size |
| frame | one message of ANSI bytes from `terminal session` |
| control / observe | the two stream kinds: control types and resizes; observe only watches |
| control plane / terminal plane | requests and events (the bridge) / terminal streams (`terminal session`) |
| split tree | herdr's layout: each split cuts a rectangle in two by a ratio |
| split id | `split_<n>_<path>`: n = place in `splits[]`; path = `root` or one digit per step (0 = first child, 1 = second) |
| ControlMaster | one shared SSH connection that later `ssh` commands reuse |
| relay | a small Perl script, sent with each SSH connection and never installed, that carries every run of a remote machine over one SSH session |
| run | the call the app makes on a machine: run a command and use its stdio |
| envelope | the base64 wrapper every remote command travels in |
| `terminal_id` / `pane_id` | herdr's id of a terminal process / of a pane slot; the pane id changes on a move to another workspace, the terminal id on a cold restart |
| cold restart / live update | the herdr server stops, its terminals end, and it starts again / a new herdr server takes over the running terminals, which keep running |
| `completion_seq` | the number of an agent's last finish (working or blocked → idle), from one counter per herdr server. herdr sets it back to null at the agent's next status change. It restarts at 0 when herdr restarts |
| health check | the loop, one per open session, that reads `session.snapshot` every 30 s, every 2 s while it fails |
| askpass | a small program `ssh` runs to ask for a password |
| `MaxSessions` | OpenSSH's limit of sessions on one connection (10 by default) |
| Simpler choice | a shortcut taken on purpose, with when to revisit it |
