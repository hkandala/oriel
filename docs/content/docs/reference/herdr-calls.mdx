## API calls

| Call | Used for | Page |
|---|---|---|
| `ping` | waiting for a server the app started | [Checks on connect](/docs/machines#checks-on-connect) |
| `session.snapshot` | all state and herdr's version, read after events; the health check every 30 s | [Reconcile](/docs/talking-to-herdr#reconcile) |
| `events.subscribe` (long-lived) | "read the snapshot again" | [Events](/docs/talking-to-herdr#events) |
| `integration.list` | the agent picker, when it opens | [Agent](/docs/plugins/terminal-and-agent#agent) |
| `workspace.create` \| `close` \| `rename` \| `move` | sidebar actions | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `tab.create` \| `close` \| `rename` \| `move` | tab bar actions | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.split` \| `close` \| `swap` \| `move` \| `resize` | split, close, drag, placing a new web or plugin pane | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `layout.apply` | create a web or plugin pane with its label and placeholder command, in a new tab; never with `tab_id` (it replaces the tab) | [Labels](/docs/plugins/labels#create) |
| `pane.rename` \| `report_metadata` | web address edits, `setArg`, `oriel_rev` | [Labels](/docs/plugins/labels) |
| `pane.send_input` | screen-text replies | [Chat view](/docs/chat-view#screen-text-chat) |
| `pane.send_keys` | special keys and Ctrl chords typed in a terminal card | [Terminal plane](/docs/talking-to-herdr#terminal-plane) |
| `pane.read` | screen-text chat, blocked panel, VoiceOver, swipe previews | [Chat view](/docs/chat-view) |
| `pane.process_info` | close check, Codex transcript | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `layout.set_split_ratio` | divider drag, double-click, ⌃⌘= | [Layout](/docs/layout) |
| `layout.export` | fallback when the leaf count is wrong | [Rebuilding the tree](/docs/layout#rebuilding-the-tree) |
| `agent.start` \| `prompt` \| `send_keys` | start an agent, reply, key buttons | [Chat view](/docs/chat-view#sending-and-answering) |

## Commands

```sh
herdr --session S remote-api-bridge
herdr --session S terminal session control|observe <terminal_id> \
    --cols C --rows R [--takeover]
herdr session list --json                           # macOS
herdr machine list --json                           # macOS, the Add Machine sheet
herdr --session S server        # remote: nohup, on request; This Mac: a launchd job (D47)
```

## Never used

`pane.focus`, `tab.focus`, `workspace.focus`, `agent.focus`, `pane.zoom`,
herdr popups, herdr plugin panes (`plugin.pane.open`), herdr's private client
socket.
