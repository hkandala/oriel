## API calls

| Call | Used for | Page |
|---|---|---|
| `session.snapshot` | all state and herdr's version of an open session, read after events and after every write; the health check every 30 s; waiting for a server the app started | [Reconcile](/docs/talking-to-herdr#reconcile) |
| `events.subscribe` (long-lived) | "read the snapshot again" | [Events](/docs/talking-to-herdr#events) |
| `integration.list` | the agent picker, when it opens | [Agent](/docs/plugins/terminal-and-agent#agent) |
| `workspace.create` \| `close` \| `rename` \| `move` | sidebar actions: new (page header `+`, workspace menu), close, rename in place, Move Up and Down, drag to reorder; folders dropped on the Dock icon | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `workspace.move_block` | drag a repository's workspace with its linked worktrees | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `tab.create` \| `close` \| `rename` \| `move` | tab bar and sidebar actions: new (also from a workspace row), close, Close Other Tabs, rename, Move Tab Left and Right, drag to reorder | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.split` \| `close` \| `move` | split (left and up add a swap), close, Move to New Tab, Move to Tab, Move to New Workspace, drag (an edge of a card in the same tab is two moves and a swap), placing a new web or plugin pane | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.swap` | drag onto a card in the same tab; the last step of a drop on a left or top edge; split left and up; with `direction`, ⌥⇧⌘ and an arrow | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.resize` | ⌃⌘ and an arrow, 5 % per press | [Dividers](/docs/layout#dividers) |
| `layout.apply` | create a web or plugin pane with its label and placeholder command, in a new tab; never with `tab_id` (it replaces the tab) | [Labels](/docs/plugins/labels#create) |
| `pane.rename` | Rename Pane; web address edits, `setArg` | [Labels](/docs/plugins/labels) |
| `pane.send_input` | screen-text replies; Go to Directory and Insert Path | [Chat view](/docs/chat-view#screen-text-chat) |
| `pane.send_keys` | special keys and Ctrl chords typed in a terminal card | [Terminal plane](/docs/talking-to-herdr#terminal-plane) |
| `pane.read` | `visible`: screen-text chat, blocked panel, VoiceOver, swipe previews, the hover card's lines for a pane that needs you; `recent`: find in a pane; `visible` again after a find scroll, for the highlights | [Chat view](/docs/chat-view) |
| `pane.process_info` | close check, Codex transcript, program icons | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls), [Program icons](/docs/ui/program-icons#when-the-app-asks-herdr) |
| `pane.get` | the keyboard card's folder for Go to Directory; the viewport's offset after a find scroll | [Command palette](/docs/ui/window#command-palette) |
| `pane.scroll` | find in a pane: scroll herdr's viewport to a match, and back to the bottom | [Find bar](/docs/ui/window#find-bar) |
| `layout.set_split_ratio` | divider drag, double-click, balance (⌃⌘=), autobalance, divider accessibility | [Layout](/docs/layout) |
| `layout.export` | fallback when the leaf count is wrong | [Rebuilding the tree](/docs/layout#rebuilding-the-tree) |
| `agent.start` \| `prompt` \| `send_keys` | start an agent, reply, key buttons | [Chat view](/docs/chat-view#sending-and-answering) |

## Commands

`herdr` here is the machine's absolute path from its login shell
([herdr on each machine](/docs/talking-to-herdr#herdr-on-each-machine)).

```sh
herdr --session S remote-api-bridge
herdr --session S terminal session control|observe <terminal_id> \
    --cols C --rows R [--takeover]
herdr --session S session list --json               # each machine, for the Open Session sheet
herdr machine list --json                           # macOS, the Add Remote Host sheet
herdr --session S server        # remote: nohup, on request; This Mac: a launchd job (D47)
git -C <root> status --porcelain=v2 --branch --untracked-files=no     # not herdr: git state of a workspace row (D67)
```

## Tests only

`pane.report_agent`: the e2e helper reports agent status on a throwaway pane.
The app never calls it.

## Never used

`pane.focus`, `tab.focus`, `workspace.focus`, `agent.focus`, `pane.zoom`,
herdr popups, herdr plugin panes (`plugin.pane.open`), herdr's private client
socket.
