## API calls

| Call | Used for | Page |
|---|---|---|
| `session.snapshot` | all state and herdr's version of an open session, read after events and after every write (each pane's `agent_session` gives its agent's session: [Session titles](/docs/ui/chat-view#session-titles), [Relaunch with Chat](/docs/ui/chat-view#relaunch-with-chat)); the health check every 30 s; waiting for a server the app started | [Reconcile](/docs/talking-to-herdr#reconcile) |
| `events.subscribe` (long-lived) | "read the snapshot again" | [Events](/docs/talking-to-herdr#events) |
| `workspace.create` \| `close` \| `rename` | sidebar actions: new (page header `+`, workspace menu), close, rename in place; folders dropped on the Dock icon. The new workspace's `root_pane` gets the [New pane](/docs/ui/new-pane) chooser | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `workspace.move_block` | Move Up and Down, drag to reorder (always with the row's group: the workspace and its linked worktrees) | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `tab.create` \| `close` \| `rename` \| `move` | tab bar and sidebar actions: new (also from a workspace row; its `root_pane` gets the chooser), close, Close Other Tabs and Close Tabs to the Right, rename, Move Tab Left and Right, drag to reorder; `move` puts a plugin card's open in a new tab right after its card's tab | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.split` \| `close` \| `move` | split (left and up add a swap), close, Replace Pane and the commands that change a pane's kind (a split, then a close of the old pane), a browser or plugin pane's create (a move beside the old pane, then a close), a plugin card's open to the side (a move beside the card), Move Pane to Tab ▸ (a tab, New Tab, New Workspace), drag (an edge of a card in the same tab is two moves and a swap; a tab dropped on another workspace or New Workspace moves pane by pane) | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.swap` | drag onto a card in the same tab; the last step of a drop on a left or top edge; split left and up; with `direction`, ⌥⇧⌘ and an arrow | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.resize` | Resize Pane (View ▸ Pane, the palette), 5 % each | [Dividers](/docs/layout#dividers) |
| `pane.rename` | Rename Pane, Reset Pane Name; a browser card's typed address goes into its label; each move inside a plugin card (a click, Back, Forward) goes into its label | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls), [Browser](/docs/ui/browser#create) |
| `layout.apply` | a browser or plugin pane: a new tab with one pane, its label and its placeholder command, never with a `tab_id`; also a link opened in a new tab, and a plugin card's open in a new tab or to the side | [Create](/docs/ui/browser#create), [Popups, links and dialogs](/docs/ui/browser#popups-links-and-dialogs), [Opening](/docs/plugins/default-plugins#opening) |
| `pane.send_input` | Go to Directory and Insert Path; an agent's launch line (or its bare command) from the chooser or Start Agent Here; Relaunch with Chat's quit command and its launch line; chat text that starts with `/`, with no Return | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `pane.send_keys` | special keys and Ctrl chords typed in a terminal card; a chat's Stop (Esc, OpenCode Esc twice); Relaunch with Chat's Stop keys while the agent works or waits, then ⌃C | [Terminal plane](/docs/talking-to-herdr#terminal-plane) |
| `pane.read` | `visible`: the hover card's lines for a pane that needs you; `recent`: find in a pane, and a Codex chat's last 8 lines every 0.5 s ([Codex's screen check](/docs/ui/chat-view#codexs-screen-check)); `visible` again after a find scroll, for the highlights | [Find bar](/docs/ui/window#find-bar) |
| `pane.process_info` | close and Replace Pane check, Go to Directory's shell check, program icons, the agent loader's failure check, a chat agent's launch marker in the foreground argv, Relaunch with Chat's wait for the shell | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls), [Program icons](/docs/ui/program-icons#when-the-app-asks-herdr) |
| `pane.get` | the keyboard card's fresh folder for New Tab, Go to Directory and Insert Path, and for a browser or plugin pane's create; the new pane of a plugin card's open; the viewport's offset after a find scroll; the agent loader's ready check, every 250 ms ([New pane](/docs/ui/new-pane#agent)); Relaunch with Chat's check that herdr let go of the agent | [Writes](/docs/talking-to-herdr#writes-are-herdr-calls) |
| `agent.prompt` | a chat's Send: `{target, text}`; herdr pastes it with bracketed paste and presses Enter | [Sending and stopping](/docs/ui/chat-view#sending-and-stopping) |
| `pane.report_metadata` | the `oriel-shown` mark on each pane in view, for float requests | [Float requests](/docs/talking-to-herdr#float-requests) |
| `pane.scroll` | find in a pane: scroll herdr's viewport to a match, and back to the bottom | [Find bar](/docs/ui/window#find-bar) |
| `layout.set_split_ratio` | divider drag, double-click, balance (⌥⌘=), equal splits after a split or move, divider accessibility | [Layout](/docs/layout) |
| `layout.export` | fallback when the leaf count is wrong | [Rebuilding the tree](/docs/layout#rebuilding-the-tree) |

An agent's `pane.report_metadata` with the token `oriel-label`, after it
renames a browser pane, is not the app's call: it only makes herdr send the
event that the rename does not
([Agents open browser panes](/docs/ui/browser#agents-open-browser-panes)).

## Commands

`herdr` here is the machine's absolute path from its login shell
([herdr on each machine](/docs/talking-to-herdr#herdr-on-each-machine)).

```sh
herdr --session S remote-api-bridge
herdr --session S terminal session control|observe <terminal_id> \
    --cols C --rows R [--takeover]
herdr --session S session list --json               # each machine: the Open Session panel, restore, "not running"
herdr --session S session stop|delete S --json      # Open Session's Stop and Delete; errors as JSON on stderr
herdr --session S server        # remote: nohup, on request; This Mac: a launchd job (D47)
```

Not herdr. A remote machine's commands (the SSH master, the relay and its login shell) are in
[The SSH connection](/docs/machines#the-ssh-connection), and the file drop upload in
[Drag and drop](/docs/ui/drag-and-drop#files-and-images). This Mac's:

```sh
$SHELL -lic '…; /usr/bin/env; …; command -v herdr'  # This Mac, at launch and at most every 30 s while herdr is not found: the login shell's environment and herdr's path
env -0                                              # This Mac: the user's keys for the server's launchd job
launchctl bootout gui/<uid>/<label>                 # This Mac: start a server (D47)
launchctl bootstrap gui/<uid> <plist>
sh -c 'command -v git'                              # once at launch: is git usable
xcode-select -p                                     # only when git is the /usr/bin/git stub
git --no-optional-locks -C <root> status --porcelain=v2 --branch --untracked-files=no   # git state of a workspace row (D67)
sh -c 'f=/tmp/oriel-copy-$1; base64 <"$f" && rm -f "$f"' sh <id>   # each machine: a copy request (talking-to-herdr#copy-requests)
```

A browser or plugin card's ([Browser](/docs/ui/browser), [State](/docs/plugins/api#state)):

```sh
sh -c 'cat "$HOME/$1"' sh .local/state/oriel/<S>/<browser or plugin id>/<iid>.json   # each machine: read the state file when the card is built
sh -c 'umask 077; f="$HOME/$1"; mkdir -p "${f%/*}" && cat >"$f.$$" && mv "$f.$$" "$f"' sh <path>   # write it, 500 ms after a navigation or a plugin's last change
sh -c 'rm -f "$HOME/$1"' sh <path>                  # a typed address, a close
find "$HOME/.local/state/oriel/<S>" -type f -mtime +30 -delete      # once on connect
ssh -F /dev/null -S <ctl> -O forward -D 127.0.0.1:<P> <target>   # a remote machine: its first browser card's proxy
ssh -F /dev/null -S <ctl> -O cancel -D 127.0.0.1:<P> <target>    # its last card went
```

A plugin card's, on the pane's machine, with `-z` and NUL-separated names so a
name can hold a line break ([File Explorer and Git](/docs/plugins/default-plugins)):

```sh
sh -c 'cd "$1" || exit; for f in * .[!.]* ..?*; do … printf "%s/\0" …; done' sh <folder>   # a folder's entries (the File Explorer's tree)
git --no-optional-locks -C <folder> status --porcelain=v1 -z --ignored -unormal -- .     # with it: the entries' letters and ignored state
sh -c 'cd "$1"; if [ "$2" ]; then git ls-files -z -co --exclude-standard; else find . -name .git -prune -o -type f -print0; fi | head -c 8388608' sh <root> git   # every path, for the filter
sh -c '[ -f "$1" ] …; wc -c <"$1"; cksum <"$1" && base64 <"$1"' sh <path> 16777216   # read a file (size, hash, bytes)
sh -c 'cksum <"$1"' sh <path>                       # has it changed (a reload check)
sh -c 'wc -c <"$1"' sh <path>                       # the info view's size
sh -c 't=$(mktemp …/.oriel-save.XXXXXX); cp -p "$1" "$t"; base64 -d >"$t"; …; mv -f "$t" "$1"' sh <path> <hash> <size>   # save: the bytes in base64 on stdin, checked by hash and size
sh -c 'ls -1Ap "$1"; git status …; git ls-files -z -m -o … | xargs -0 cat; … | cksum' sh <path>   # a remote machine: the 2 s check while a card shows
git -C <folder> rev-parse --show-toplevel           # the root for File Explorer and Git
git --no-optional-locks -C <root> status --porcelain=v1 -z --untracked-files=all   # the tree's letters; the Git home's staged and unstaged changes
git --no-optional-locks -C <root> status --porcelain=v2 --branch …   # the Git home: the branch, ahead and behind
git -C <root> for-each-ref --format=%(HEAD)%(refname) refs/heads refs/remotes   # the Git home: the branch menu
git -C <root> log --branches --remotes --tags HEAD -n 500 --topo-order --no-show-signature --decorate=full --format=%H%x1f%P%x1f%an%x1f%at%x1f%D%x1f%s --   # the Git home's history of every branch
env GIT_TERMINAL_PROMPT=0 git -C <root> <write>     # the Git home's writes, one at a time: fetch --all, pull, -c push.autoSetupRemote=true push, --literal-pathspecs add -A -- <path>, --literal-pathspecs reset -q -- <path>, add -A, reset -q, commit -m <message>, switch [--track] <branch>
sh -c 'cd "$1"; h=$(git rev-parse -q --verify HEAD || git hash-object -t tree /dev/null); { git diff … "$h" --; git ls-files -z -o --exclude-standard | head -c 65536 | xargs -0 -r -n 1 git diff … --no-index -- /dev/null; } …' sh <root> …   # a diff: Uncommitted, with untracked files
git -C <root> show --no-color --no-ext-diff -M -m --first-parent --format= <hash>   # a diff: one commit
```

A plugin's `oriel.run` runs its argv on the card's machine, inside the envelope.
This Mac watches files and folders with FSEvents, with no command.

Plugin packages, on This Mac only ([Packages and installs](/docs/plugins/packages)):

```sh
sh -c 'command -v "$1"' sh npm|pnpm|bun            # the package manager: the lockfile's, else the first found
npm pack <spec> --pack-destination <staging> --json --ignore-scripts   # an npm: source
tar -xzf <tarball> -C <staging>
env GIT_TERMINAL_PROMPT=0 git clone --quiet -- <url> <folder>          # a git: source
env GIT_TERMINAL_PROMPT=0 git -C <folder> checkout --quiet <ref> --
sh -c 'cd "$1" && shift && exec "$@" 2>&1' sh <package> npm ci --no-audit --no-fund --ignore-scripts --legacy-peer-deps   # its dependencies (pnpm, bun: their flags)
sh -c 'cd "$1" && shift && exec "$@" 2>&1' sh <package> npm run --silent build   # its build script: at install, Reload Plugin, Build
```

A chat's, on the pane's machine ([Chat view](/docs/ui/chat-view)):

```sh
sh -c '<prepare>' sh <token or file>                # before a Pi or OpenCode launch: write the extension or plugin, the password, the 30-day sweep
sh -c 'f=…; while [ ! -f "$f" ]; do sleep 0.5; done; …; awk "$4"… <fifo & exec tail -c +N -F "$f" >fifo' sh <path> <offset> <inode> <skip>   # follow a side file or a transcript, dropping the lines its parser skips
sh -c 'while :; do …; sleep 0.3; done' sh .claude/sessions/<pid>.json   # watch Claude Code's session record
sh -c 'test -f "$HOME/$1/ask"' sh .cache/oriel/chat/T   # Claude Code: does the question's hook still wait
sh -c 'rm -f "$HOME/$1/ask"' sh .cache/oriel/chat/T     # the question was answered in the terminal: its hook ends
sh -c 'd="$HOME/$1"; [ -f "$d/ask" ] && cat >"$d/answer.tmp" && mv "$d/answer.tmp" "$d/answer"' sh <folder>   # its answer
curl -sN -K - http://127.0.0.1:<port>/event           # OpenCode's events; the password from a here-document
curl -s -K - http://127.0.0.1:<port>/session/<id>/message   # its history; also GET /permission, /question, POST /…/<id>/reply
```

Any agent pane's, on its machine ([Session titles](/docs/ui/chat-view#session-titles)):

```sh
sh -c '{ <script>; } 2>/dev/null' sh <session>      # its session's title, when the session, the terminal title or the status changes
```

## Tests only

The UI tests call these on throwaway panes; the app never does:
`pane.report_agent` and `pane.release_agent` (agent status), `pane.send_text`
(type into a pane) and `pane.zoom` (a tab zoomed as a herdr TUI zooms it).

## Never used

`pane.focus`, `tab.focus`, `workspace.focus`, `agent.focus`, `pane.zoom`,
herdr popups, herdr plugin panes (`plugin.pane.open`), herdr's private client
socket.
