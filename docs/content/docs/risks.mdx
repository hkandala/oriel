---
title: "Risks and known limits"
description: "Known risks, their effect and the plan for each"
---

| Risk | Effect | Plan |
|---|---|---|
| A SwiftUI strip with many Metal surfaces | jank, lost gestures | [spike S1](/docs/build-order#s1-strip); fallback is a paging container |
| libghostty answers terminal queries that herdr already answered | stray bytes such as `^[[?1;2c` typed into shells | a pinned libghostty-spm build with uHerdr's response-suppression patch; checked in spike S1 |
| The toolbar squeezes the tab bar | tabs overflow | built as the fallback: a hidden title bar with the app's own title row, so [spike S2](/docs/build-order#s2-tab-bar) is moot |
| Citadel exec channels on iOS (stdin, long-lived channels, close) | the iOS app cannot talk to herdr | [spike S7](/docs/build-order#s7-ios-transport); a thin iOS slice early in the build order |
| A dead SSH link after a network change | requests hang | 10 s timeout on every `call()`; the [health check](/docs/machines#health-check) every 30 s |
| herdr updated but not restarted | terminal streams fail; the API works | the card shows herdr's error text and **Retry** |
| Pane order in `layouts[]` is not a documented contract | wrong tree | leaf-count check, then `layout.export` |
| Bridge cost per call | 18–130 ms plus network | hidden by the snapshot pacing; direct socket if a profile says so |
| herdr does not report PTY columns | a phone watcher uses a fixed size | ask herdr for the field if needed |
| A herdr TUI on the same tab | shared ratios; our control pins the PTY size | accepted |
| `pane.swap` marks the tab seen in herdr | TUI users lose a done marker | accepted; swap only follows a drag |
| Transcript formats change | full chat breaks for one agent | lenient parsers; screen text and terminal still work |
| iOS drops connections in the background | no live updates | reconnect and snapshot on return; a push relay later ([Future work](/docs/future-work)) |
| herdr's stream keeps OSC 52 copy requests | copy from a remote program (vim `"+y`) does not reach the device clipboard | select text in the card; later, herdr's clipboard support |
| A hung plugin page | its card stops responding | WebKit runs each page in its own process; the card offers **Refresh** |
| Plugin HTML built from repository text | a script in a repository file runs in the plugin page | a Content Security Policy allows only the plugin's own scripts; core plugins insert text, not HTML |
| A malicious plugin the user installed | anything the user can do on machines where its panes open, including network use from there | consent sheet in plain words; This Mac confirm; source shown and pinned to a commit |
| A herdr cold restart | web and plugin panes come back as plain shells with their labels; cards still work | accepted; upstream ask ([Future work](/docs/future-work)) |
| Labels written by a hostile machine | a web page or plugin card opening by itself | a web address outside the approved origins and the safe list needs a click; plugins act only on that machine |
| DNS rebinding against loopback forwards | a page reaches a forwarded dev server by another name | per-machine loopback rules; accepted residual risk |
| The pill panel's focus behavior | the reply box may not take keys, or a click may not open the app | [spike S5](/docs/build-order#s5-pill) |
| Web view memory (120–200 MB each, web pages and plugin cards) | memory growth | one cap of 6 live web views on Mac and iPad and 2 on iPhone; evict on memory pressure |
| libghostty-spm and Citadel are third-party builds | updates lag; supply chain | exact pins; reviewed updates; SwiftTerm as a fallback renderer |
| A server with `AllowTcpForwarding no` | remote `localhost` pages cannot load | the card says so; Tailscale or LAN addresses still load; a server helper later ([Future work](/docs/future-work)) |
| A local forward port is open to other local users | another account could reach the dev server | accepted for a single-user Mac |
