## Where things live

One rule decides where each new thing goes (D57):
- **Anything that takes space in the layout** is a multiplexer pane.
- **Transient UI** (the palette, popovers, hover, chips) lives in app memory
  only.
- **Per-device settings** live in app storage.

## Every piece of data

| Data | Owner | Where |
|---|---|---|
| Workspaces, tabs, panes, order, labels (a browser pane's kind, iid and typed address: [The label](/docs/ui/browser#the-label)) | herdr | `session.snapshot` |
| Split tree and ratios | herdr | `snapshot.layouts[]` |
| Terminal content and PTY | herdr | `terminal session` frames |
| Agent kind, status, `completion_seq` | herdr | `agents[]`, `panes[]` |
| A machine's sessions | herdr | `herdr session list --json`, run on the machine |
| Remote machines: name, SSH target, icon, id | app, disk | `UserDefaults`, JSON under `machines` |
| Settings: appearance, interface style, text size and Focus Follows Mouse ([Settings](/docs/ui/settings)); the Agents view's folded groups (`agentsFolded`); a floating pane's window frame, per pane | app, disk | app storage (`UserDefaults`) |
| Per window: the machine's id (`machine`), the names of its open pages (`pages`), the page in view (`page`), each page's selected workspace and tabs and its floating panes with their Stay on Top (`selection`, one JSON string), sidebar shown or hidden (`sidebar`), sidebar view (workspaces or agents, `agents`) and its sort (`agentSort`), and sidebar width (`sidebarWidth`) | app, disk | `@SceneStorage`, one set per window |
| Per page of a window: the selected workspace, the tab per workspace, the keyboard card per tab, the zoomed card. Per open session: its `HostStore`, made on first use. Per session: which window controls it ([Control between windows](/docs/talking-to-herdr#control-between-windows)). | app, per device | memory |
| Seen values and the time of each status change (Agents view), program icons, git state of each workspace, a divider's ratio while it is dragged | app, per device | memory |
| A browser pane's page and its back and forward list | the pane's machine | `$HOME/.local/state/oriel/<session>/browser/<iid>.json` ([State on the machine](/docs/ui/browser#state-on-the-machine)) |
| Approved browser origins, the newest 200 per machine | app, disk, per device | `UserDefaults`, a list under `browserApprovals.<machine id>` ([When a page loads by itself](/docs/ui/browser#when-a-page-loads-by-itself)) |
| Browser cookies, storage and cache, one store per machine | WebKit, disk, per device | `~/Library/WebKit/<bundle id>/WebsiteDataStore/<machine id>/` ([Profiles](/docs/ui/browser#profiles)) |
| The choosers of new panes ([New pane](/docs/ui/new-pane)); browser cards' web views, by terminal id | app, per device | memory |
| ControlMaster sockets | app | `~/Library/Caches/oriel/`, while running |

<Callout title="Nothing the app saves describes herdr's state">
The only exception is each window's restore state: the names of its pages.
A page whose session no longer runs is skipped. A fresh install on a new Mac rebuilds
every workspace, tab and pane from herdr.
</Callout>

## Which pages a window opens

- A restored window opens the pages in `pages` again, in order, and shows
  `page`, each with its `selection`. A name that no longer runs is skipped.
  macOS hands a restored window its scene storage a moment after the window
  first shows, so the window waits for it (at most 1 s) before it opens a
  page.
- With `-session` on the command line, every window opens only that session
  (a run against a throwaway session never reopens another), with its saved
  selection.
- With none left, or in a new window, the first page is the session named by
  the `-session` launch argument, else `default`. On This Mac the app starts
  it when it is stopped (a launchd job, D47). It never opens another session
  by itself.
- A new window opened for a machine (the machine menu, Add Remote Host, ⌘N
  in a window of that machine) is on that machine.
- Nothing writes a session name to `UserDefaults`. `-session` is read from
  the argument domain only.
