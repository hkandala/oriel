## Where things live

One rule decides where each new thing goes (D57):
- **Anything that takes space in the layout** is a multiplexer pane with a
  label: terminals, agents, web pages and plugin panes.
- **Transient UI** (the palette, popovers, hover, chips) lives in app memory
  only.
- **Per-device settings** live in app storage.

## Every piece of data

| Data | Owner | Where |
|---|---|---|
| Workspaces, tabs, panes, order, labels | herdr | `session.snapshot` |
| Split tree and ratios | herdr | `snapshot.layouts[]` |
| Terminal content and PTY | herdr | `terminal session` frames |
| Agent kind, status, `completion_seq`, transcript pointer | herdr | `agents[]`, `panes[]` |
| Web page address the user typed | herdr | pane label `oriel:web#<iid> <url>` |
| Plugin, pane kind, instance id, argument | herdr | pane label `oriel:<plugin>[/<pane>]#<iid> <arg>` |
| Plugin instance state; a web card's current address and scroll position | the machine | `$HOME/.local/state/oriel/<session>/<plugin-id>/<iid>.json` (`web` for web cards; [State and restore](/docs/plugins/state)) |
| Chat history | the agent | its transcript file on the machine |
| A machine's sessions | herdr | `herdr session list --json`, run on the machine |
| Remote machines: name, SSH target, icon, id | app, disk | `UserDefaults` (on macOS the add dialog offers `herdr machine list`) |
| iOS SSH key and pinned host keys | app, disk | Secure Enclave, Keychain |
| Settings: appearance, interface style, text size and pane options ([Settings](/docs/ui/settings)); pill settings | app, disk | app storage (`UserDefaults`) |
| Per window: the machine (once remote machines exist), the names of its open pages (`pages`), the page in view (`page`), each page's selected workspace and tabs (`selection`, one JSON string), sidebar shown or hidden (`sidebar`), sidebar view (workspaces or agents, `agents`) and its sort (`agentSort`), and sidebar width (`sidebarWidth`) | app, disk | `@SceneStorage`, one set per window |
| Plugin code and source record | app, disk | `Application Support/Oriel/plugins/` |
| Plugin consent and This Mac answers | app, disk | `UserDefaults` |
| Plugin preferences | app, disk | `UserDefaults`, passwords in the Keychain |
| Approved web origins per machine, the web safe list | app, disk | `UserDefaults` |
| Web cookies | WebKit | one data store per machine |
| Per page of a window: the selected workspace, the tab per workspace, the keyboard card per tab, the zoomed card. Per open session: its `HostStore`, made on first use. Per session: which window controls it ([Control between windows](/docs/talking-to-herdr#control-between-windows)). Chat or terminal per pane, drafts | app, per device | memory |
| Seen values and the time of each status change (Agents view), program icons, git state of each workspace, a divider's ratio while it is dragged | app, per device | memory |
| ControlMaster sockets, port forwards | app | `~/Library/Caches/oriel/` (macOS), while running |

`<session>` is the herdr session name. `$HOME` is the machine's home folder;
commands start there, so paths are relative to it.

<Callout title="Nothing the app saves describes herdr's state">
The only exception is each window's restore state: the names of its pages.
A page whose session no longer runs is skipped. A fresh install on a new device rebuilds
every workspace, tab, pane, web page and plugin pane from
herdr's labels and the machines' state files
([State and restore](/docs/plugins/state)).
</Callout>

## Which pages a window opens

- A restored window opens the pages in `pages` again, in order, and shows
  `page`, each with its `selection`. A name that no longer runs is skipped.
  macOS hands a restored window its scene storage a moment after the window
  first shows, so the window waits for it (at most 1 s) before it opens a
  page.
- With `-session` on the command line, every window opens only that session
  (a run against a throwaway session never reopens another), with its saved
  selection.
- With none left, or in a new window, the first page is the session named by
  the `-session` launch argument, else `default`. On This Mac the app starts
  it when it is stopped (a launchd job, D47). It never opens another session
  by itself.
- A new window opened for a machine (the machine menu, Add Remote Host, ⌘N
  in a window of that machine) is on that machine.
- Nothing writes a session name to `UserDefaults`. `-session` is read from
  the argument domain only.
