## Where things live

One rule decides where each new thing goes (D57):
- **Anything that takes space in the layout** is a multiplexer pane with a
  label: terminals, agents, web pages and plugin panes.
- **Transient UI** (the palette, popovers, hover, chips) lives in app memory
  only.
- **Per-device settings** live in app storage.

## Every piece of data

| Data | Owner | Where |
|---|---|---|
| Workspaces, tabs, panes, order, labels | herdr | `session.snapshot` |
| Split tree and ratios | herdr | `snapshot.layouts[]` |
| Terminal content and PTY | herdr | `terminal session` frames |
| Agent kind, status, `completion_seq`, transcript pointer | herdr | `agents[]`, `panes[]` |
| Web page address the user typed | herdr | pane label `oriel:web#<iid> <url>` |
| Plugin, pane kind, instance id, argument | herdr | pane label `oriel:<plugin>[/<pane>]#<iid> <arg>` |
| Plugin instance state; a web card's current address and scroll position | the machine | `$HOME/.local/state/oriel/<session>/<plugin-id>/<iid>.json` (`web` for web cards; [State and restore](/docs/plugins/state)) |
| Chat history | the agent | its transcript file on the machine |
| This Mac's sessions (macOS) | herdr | `herdr session list` |
| Remote machines: target, session, label, id | app, disk | `UserDefaults` (on macOS the add sheet offers `herdr machine list`) |
| iOS SSH key and pinned host keys | app, disk | Secure Enclave, Keychain |
| Display preferences, pill settings | app, disk | `UserDefaults` |
| Window restore ids (machine, workspace, tab), sidebar expand state | app, disk | `@SceneStorage` |
| Plugin code and source record | app, disk | `Application Support/Oriel/plugins/` |
| Plugin consent and This Mac answers | app, disk | `UserDefaults` |
| Plugin preferences | app, disk | `UserDefaults`, passwords in the Keychain |
| Approved web origins per machine | app, disk | `UserDefaults` |
| Web cookies | WebKit | one data store per machine |
| Zoomed card, chat or terminal per pane, seen values, drafts | app, per device | memory |
| ControlMaster sockets, port forwards | app | `~/Library/Caches/oriel/` (macOS), while running |

`<session>` is the herdr session name. `$HOME` is the machine's home folder;
commands start there, so paths are relative to it.

<Callout title="Nothing the app saves describes herdr's state">
The only exception is the window restore ids. A restore id that is gone falls
back to herdr's focused workspace. A fresh install on a new device rebuilds
every workspace, tab, pane, web page and plugin pane from
herdr's labels and the machines' state files
([State and restore](/docs/plugins/state)).
</Callout>
