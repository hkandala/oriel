## Terminal

Terminal is the pane as the app makes it today: `pane.split` or
`tab.create`. herdr starts the user's shell, and the card draws the frame
stream ([Terminal plane](/docs/talking-to-herdr#terminal-plane)). The
chat|term switch shows the screen text instead
([Screen-text chat](/docs/future-work/chat-view#screen-text-chat)).

## Agent

An agent pane is a pane where herdr detected an agent (`pane.agent` is set,
for example `claude`, `codex`, `pi`).

- **Start:** the [New pane](/docs/ui/new-pane#agent) chooser and Start Agent
  Here type the agent's command (`claude`, `codex`, `pi`, `opencode`) into the
  pane's shell, show a loader until the agent is ready, then show its TUI.
- **Icon:** the agent's program icon, as today
  ([Program icons](/docs/ui/program-icons)).
- **View:** terminal by default on the Mac and iPad, chat on iPhone. The chat|term
  switch changes it ([Chat view](/docs/future-work/chat-view)).
- **Later:** list only the agents herdr finds on the machine, from the
  `integration.list` entries with `available: true` (the command is on the
  herdr server's `PATH`), read each time the list opens; and flags per agent
  set by the user. Simpler choice now: the four agents always show, and a
  missing one shows "command not found" in its terminal.

## Image paste

Paste an image into a terminal or agent card, or into the chat reply box, and
the agent gets it as a file on its own machine.

1. ⌘V (or Paste on iOS) with an image and no text on the clipboard. The app encodes it as PNG.
2. It copies the image to the pane's machine as a dropped file is copied
   (`Exec.upload`, [Drag and drop](/docs/ui/drag-and-drop#files-and-images)):
   a new folder of its own in the machine's temporary folder, at most 16 MB,
   over the relay on a remote machine. It gets the copy's path back.
3. It pastes that path into the pane like a text paste, or adds it to the
   chat draft. Agents such as Claude Code read the image from the pasted
   path.

- The same steps on This Mac and over SSH. herdr's own remote client, uHerdr,
  collie, termote and roamgate do the same: upload, then paste the path.
- An image over 16 MB shows "Image too large to paste", and nothing is sent.
- Rejected: image bytes through the terminal (herdr's stream and agents do
  not take them); a server helper.
