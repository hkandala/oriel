Not built. Today the app shows an agent that you start in a terminal, with its
status; it cannot start one, and a pasted image is not sent. This page is the
design ([Pane kinds and plugins](/docs/future-work/plugins)).

## Terminal

The Terminal row makes a pane as the app does today: `pane.split` or
`tab.create`. herdr starts the user's shell, and the card draws the frame
stream ([Terminal plane](/docs/talking-to-herdr#terminal-plane)). The
chat|term switch shows the screen text instead
([Screen-text chat](/docs/future-work/chat-view#screen-text-chat)).

## Agent

An agent pane is a pane where herdr detected an agent (`pane.agent` is set,
for example `claude`, `codex`, `pi`).

- **Picker:** the `integration.list` entries with `available: true` (the
  command is on the herdr server's `PATH`), read each time the picker opens,
  so a newly installed agent shows at once. The kind is the entry's `label`.
  Simpler choice: agents without a herdr integration are not listed. Start
  them from a terminal, and herdr still detects them. Revisit when users ask
  for agents that herdr has no integration for.
- **Start:** split or new tab, then
  `agent.start {name: "<kind>-<4 random [a-z0-9]>", kind, pane_id}`.
  - `name` must match `[a-z][a-z0-9_-]{0,31}` and be unique on the machine.
  - A new shell may not be ready: herdr returns `agent_pane_busy`, and the app
    retries every 250 ms for up to 5 s.
  - `agent.start` types the command and returns at once. If no agent appears
    within 10 s, the card shows "Agent did not start" and the last screen
    lines.
- **Icon:** the agent's program icon, as today
  ([Program icons](/docs/ui/program-icons)).
- **View:** terminal by default on the Mac, chat on iPhone. The chat|term
  switch changes it ([Chat view](/docs/future-work/chat-view)).

Why `integration.list`: one call, herdr checks the `PATH`, and a newly
installed agent shows at once. Rejected: probing every agent with
`command -v`; a list read once on connect.

## Image paste

Paste an image into a terminal or agent card, or into the chat reply box, and
the agent gets it as a file on its own machine.

1. ⌘V with an image and no text on the clipboard. The app encodes it as PNG.
2. It copies the image to the pane's machine as a dropped file is copied
   (`Exec.upload`, [Drag and drop](/docs/ui/drag-and-drop#files-and-images)):
   a new folder of its own in the machine's temporary folder, at most 16 MB,
   over the relay on a remote machine. It gets the copy's path back.
3. It pastes that path into the pane like a text paste, or adds it to the
   chat draft. Agents such as Claude Code read the image from the pasted
   path.

- The same steps on This Mac and over SSH. herdr's own remote client, uHerdr,
  collie, termote and roamgate do the same: upload, then paste the path.
- An image over 16 MB shows "Image too large to paste", and nothing is sent.
- Rejected: image bytes through the terminal (herdr's stream and agents do
  not take them); a server helper.
