None of this is built. Smaller deferrals are marked "Simpler choice" on their
own pages.

## Maybe later

- **An iPhone and iPad app.** The same machines over SSH: one pane per page on
  iPhone, the Mac layout on iPad. Alerts while the app is closed would need a
  small stateless push relay.
- **A chat view** for an agent pane: its transcript file tailed and drawn as
  messages, with replies sent through herdr's `agent.prompt`.
- **Floating status pills** on the screen edge that show who needs you while you
  are in another app.
- **More pane kinds:** an agent picker, web pages, and plugins (small web pages
  in a native web view). Image paste into agents.
- **A Settings window** for the settings that have no menu item today (terminal
  font, cursor, Option as Alt, copy on select, notification switches). It must
  meet the design bar; a stock tabbed form was tried and dropped.
- **herdr's machines in Add Remote Host**, and reordering machines.
- **Bundling herdr** with the app, so a Mac without herdr can still show its own
  sessions.
- **More multiplexers** (Rex, tmux) behind the
  [`Multiplexer` interface](/docs/architecture#the-multiplexer-interface).
- **A small server helper**: one program per machine that carries every call on
  one SSH channel. Only when SSH session limits, latency or a server without
  TCP forwarding make it necessary.

## Waiting on herdr

- **herdr's popup in a floating window.** The API gives the popup no pane or
  terminal id and sends no event when it opens or closes.
- **Panes started with a command after a cold restart** come back as plain
  shells. The ask: restore them with their `launch_argv`, opt-in
  ([discussion #1367](https://github.com/herdrdev/herdr/discussions/1367)).
- **Named keys on the terminal stream** (`terminal.input` with `keys`), so all
  input takes one path.
- **OSC 7501** (a program reports its status with an escape sequence;
  [draft PR #5172](https://github.com/herdrdev/herdr/pull/5172)): show its
  message on needs-you and finished rows and in notifications.

## Left out on purpose

- Tearing a tab off into a new window.
- Key sequences and custom shortcuts.
- Traffic lights inside the tab bar (needs private API).
- Jump to prompt (needs OSC 133 marks from the shell).
- A font size per pane, paste confirmation, an installer for agent integrations.
- Many themes, a theme editor, a compact density.
