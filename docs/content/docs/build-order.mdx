## Spikes

Run each one before the step that needs it. Each one has pass criteria.

### S1 strip

A paged SwiftUI `ScrollView` on macOS and iPad with 3 pages × 3 libghostty
surfaces and 2 web views (a web page and a plugin card). Pass:
- a sideways swipe pages from anywhere; vertical scroll reaches the terminal;
- views survive page changes and zoom; no dropped frames at 120 Hz;
- window and sidebar resizes keep the page;
- iOS swipe-back on page 0 and the iPad portrait sidebar behave;
- with the patched libghostty build, `printf '\e[c'`, `printf '\e[6n'` and an
  OSC 11 color query in a pane produce no second reply;
- IME composition and dead keys reach `terminal.input`.

### S2 tab bar

12 capsules in a `ToolbarItem`: no overflow, no double glass, the marker
follows the scroll. gorex does not answer this, because it uses no Apple glass
API.

### S3 ssh

- One prompt per host with 8 parallel runs at connect.
- The ControlPath works; the Local Network alert appears.
- The askpass script works in a notarized build.
- Done: closing stdin ends every child and frees the pane, also over SSH and
  after an app crash ([Run and dial](/docs/talking-to-herdr#run-and-dial)).
- A macOS privacy prompt raised inside a pane never names Oriel.

### S4 Codex

Which process holds the rollout file open.

### S5 pill

- Typing in another app loses no key.
- The first click on a peeked pill card only activates it. Key buttons keep
  the app inactive.
- The reply box takes focus, ⌘V and Enter. The keyboard returns after close.
- Transparent areas click through. The pill shows over full-screen apps and
  on every Space.
- **Open in app** activates the app at the pane. `.passive` notifications land
  quietly. No idle wake-ups.

### S6 plugins

- 6 live plugin cards plus 9 terminals in the strip hold frame time and
  stay under the memory budget.
- The content rule and the Content Security Policy block every load and
  script that is not the plugin's own; `window.oriel` is in place before the
  page's first script.

### S7 iOS transport

Citadel exec channels, before any iOS work. Pass:
- `call()` writes stdin and then closes it while the channel stays open for
  the reply (herdrup writes stdin only inside `withExec`, and Heeler dropped
  Citadel);
- a long-lived channel streams stdin and stdout (`terminal session control`
  and the event stream);
- closing a channel ends the remote command, and the server frees the session;
- a Secure Enclave P-256 key authenticates; 8 parallel channels work;
- a `direct-tcpip` channel carries a web page: an in-app listener on
  `127.0.0.1:<P>` pipes each connection into its own channel, and a dev
  server loads in a web view at full speed.

## Build order

**v0 is built** (the repository's `plan/`): This Mac only, with the session
picker, the sidebar of workspaces and tabs, the strip with swipes between
tabs, herdr's splits, live terminals, close, split and zoom, new tabs,
workspaces and sessions, and the ⌘K palette. The steps below follow from
there.

| Step | What |
|---|---|
| 0 | Spikes S1–S7, for the parts v0 did not cover |
| 1 | **Finish This Mac:** divider drag and keyboard resize, drag and drop, renames and reorders, the agreed window layout (several windows, session pages, the Agents view, git state, Open Session), "seen" |
| 2 | **Remote machines (Mac):** the app's machine list (with herdr's machines in the add sheet), ControlMaster, askpass, the machine menu, notifications |
| 2b | **Thin iOS slice:** Citadel connect, snapshot, sidebar, one terminal stream |
| 3 | **Pane kinds and chat:** the plugin registry and picker; placeholder panes with `layout.apply`; the web page with `run` and `dial` (same-port forwards, the Open :port chip, the ports list); transcript and screen-text chat; image paste |
| 4 | **Plugin system:** the plugin host (a web view per card, `window.oriel`, the content rule and CSP); the Git history, Diff and Markdown plugins; install and dev mode |
| 5 | **Floating pills (macOS)** |
| 6 | **Full iPadOS and iOS:** the compact layout, the reply box, the key bar, the `dial` listener for web pages, background handling, accessibility on iOS |
| 7 | **Later:** [Future work](/docs/future-work) |
